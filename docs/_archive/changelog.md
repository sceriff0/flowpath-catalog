# Changelog

FlowPath is a suite of independent extensions, each with its **own** changelog
and release history. There is no single combined version number — the
[catalog](catalog.md) tracks the latest release of each.

## Catalog history

The catalog's own history — which extension versions were published when — is
in the [`flowpath-catalog` commit log](https://github.com/sceriff0/flowpath-catalog/commits/main)
and reflected in [`catalog.json`](https://github.com/sceriff0/flowpath-catalog/blob/main/catalog.json).

!!! info "Keeping versions current"
    The version numbers shown across this site reflect the catalog at the time
    of writing. Your QuPath extension manager always offers the newest release
    compatible with your QuPath version — see [Compatibility](compatibility.md).
