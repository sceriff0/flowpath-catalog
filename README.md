# FlowPath Extension Catalog

Extension catalog for the FlowPath QuPath extension suite.

## Extensions

| Extension | Description |
|-----------|-------------|
| [FlowPath - GatingTree](https://github.com/sceriff0/qupath-extension-flowpath) | Interactive tree-based cell phenotyping with hierarchical gates |
| [FlowPath - qUMAP](https://github.com/sceriff0/qupath-extension-qumap) | UMAP dimensionality reduction and visualization |

## Usage

Add this catalog URL in QuPath's Extension Manager:

```
https://raw.githubusercontent.com/sceriff0/flowpath-catalog/main/catalog.json
```
