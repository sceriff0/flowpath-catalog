# FlowPath — QuPath Extension Suite

A suite of extensions for [QuPath](https://qupath.github.io/) that bring **flow cytometry-inspired analysis tools** to multiplexed tissue imaging. Designed to make single-cell exploration interactive, visual, and accessible — right inside QuPath.

## Available Extensions

| Extension | What it does |
|-----------|-------------|
| [FlowPath - GatingTree](https://github.com/sceriff0/qupath-extension-flowpath-gatingtree) | Interactive tree-based cell phenotyping using hierarchical gates — classify cells the way you would on a flow cytometer |
| [FlowPath - qUMAP](https://github.com/sceriff0/qupath-extension-flowpath-qumap) | UMAP dimensionality reduction and visualization — explore high-dimensional measurement data in 2D |

## Getting Started

1. Open **QuPath** (v0.7.0 or later)
2. Go to **Extensions > Extension Manager**
3. Add the following catalog URL:

```
https://raw.githubusercontent.com/sceriff0/flowpath-catalog/main/catalog.json
```

4. Browse the available FlowPath extensions and install the ones you need

## About

FlowPath extends [QuPath](https://qupath.github.io/), an open-source platform for bioimage analysis, with tools familiar to anyone who has worked with flow cytometry software. Whether you are gating cell populations or reducing dimensions to find structure in your data, FlowPath aims to make these workflows intuitive within QuPath's ecosystem.
